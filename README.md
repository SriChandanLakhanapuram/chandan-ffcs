# FFCS-inator

A local timetable planner for FFCS. Choose courses, faculty, and slots to generate and compare possible timetables. Course selections are stored in your browser.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). No account or database configuration is needed.

## Build for production

```bash
npm run build
npm start
```
